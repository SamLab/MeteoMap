# Design: ближайшая строка «Предупреждений» — значения по моделям

Дата: 2026-11-17

## Проблема

Первая (ближайшая) строка дождя иногда оставалась голой:

```
Завтра с 08ч до 09ч
```

Причина — разные источники данных у интервала и у его деталей:

1. Начало строки ищется по моделям: первый час, где хотя бы одна модель даёт
   дождевой код **или** осадки ≥ 0.1 мм.
2. Осадки и вероятность брались из консенсуса (`weighted`). Если дождь даёт
   одна модель, консенсус сухой (0 мм, 0%), и оба блока скрывались — на экране
   оставался только интервал.
3. Число моделей считалось по другому правилу: при непустом коде модель
   учитывалась только по коду, поэтому модель со снеговым кодом 71 и осадками
   0.1 мм не попадала в «по N моделям», хотя именно по ней находился час.

## Решение

- `rainModelRange` (число моделей в ближайшей строке) использует то же правило,
  что и поиск первого часа: дождевой код **или** осадки ≥ 0.1 мм. Код больше не
  мешает учитывать осадки.
- Новая `rainModelSpan(a,b)` собирает минимум-максимум осадков и вероятности по
  моделям, которые дают осадки в часах интервала.
- Ближайшая строка печатает эти значения через `wetValAll`: нули сохраняются,
  поэтому строка всегда содержит мм и %, даже если они нулевые.
- Подтверждённая строка не изменилась: по-прежнему консенсус (`wetSpan`),
  нулевой максимум мм или % не показывается.

Пример после изменения:

```
Завтра с 08ч до 09ч на 0.1мм с 0% · по 1 модели
```

## Тесты

- `test_warnings_nearest_row_uses_one_model_threshold_and_first_dry_boundary`:
  ближайшая строка использует `rainModelSpan`/`wetValAll`, а `rainModelRange`
  считает по правилу «код или осадки ≥ 0.1 мм».
- `test_warnings_nearest_count_and_span_come_from_models` (node): модель со
  снеговым кодом и осадками 0.1 мм считается; нулевая вероятность сохраняется;
  диапазоны по моделям и часам считаются верно.
- `test_warnings_span_shows_ranges_min_to_max` не изменился — это поведение
  подтверждённой строки.
