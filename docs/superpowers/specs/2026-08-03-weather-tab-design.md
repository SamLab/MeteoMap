# Дизайн: MeteoMap — вкладка «Погода» (обзор погоды для непрофессионалов)

Дата: 2026-08-03
Статус: черновик (на ревью)

## 1. Цель

Добавить в MeteoMap вкладку **«Погода»**, которая показывает погоду в удобном, понятном
непрофессионалу виде: текущие условия, прогноз по часам, прогноз на 10 дней и подробный
прогноз на 10 дней. Оформление блоков повторяет Яндекс.Погоду (текущие условия, часы,
10 дней) и погоду 76.ру (подробный 10-дневный прогноз по частям суток).

Все числа на вкладке — **взвешенный консенсус** (единый прогноз, учитывающий точность
моделей за последние 7 дней).

Вкладка «Погода» — первая в списке и активна по умолчанию при открытии сайта.

## 2. Изменения данных (meteo.py)

### 2.1 Горизонт прогноза

- `FORECAST_DAYS = 7 → 10`. Влияние: график прогноза и таблица сравнения тоже станут
  на 10 дней (168 → 240 часов). Вкладка «Точность» не меняется (верификация 7/30 дней).

### 2.2 Новые дневные переменные

В `DAILY_VARIABLES` добавить:

- `precipitation_probability_max` — вероятность осадков за день (%);
- `sunrise`, `sunset` — строки времени восхода/заката в `TIMEZONE`.

Обработка в `build_payload`/`assemble_consensus`:

- `precipitation_probability_max` — числовая, считается как обычный дневной консенсус
  (среднее по доступным моделям), как существующие `temperature_2m_max` и т.п.
- `sunrise`/`sunset` — **строки**; в дневной консенсус попадают из первой модели, у
  которой они есть (тот же механизм, что уже используется для `daily_time`). Среднее
  по строкам не считается.

### 2.3 Payload

В `build_payload` уже есть `daily` (словарь переменная → массив) и `daily_time`.
Добавленные переменные попадают в этот же `daily`. Дополнительно ничего не вводится:
все производные значения (части суток, направления ветра, тексты погоды) считаются в JS.

### 2.4 Тесты (pytest, `tests/`)

- `FORECAST_DAYS` → 10: в payload длина `time` = 240, `daily_time` = 10 дат.
- В `payload["daily"]` есть `precipitation_probability_max`, `sunrise`, `sunset`.
- `sunrise`/`sunset` — строки (не None) хотя бы у одного дня.

## 3. Изменения UI (template.html)

### 3.1 Вкладка

- В `.tabs` кнопка **«Погода»** — первая (до «Прогноз»), `data-tab="weather"`.
- Панель `<div id="tab-weather" class="panel">`.
- Список вкладок в JS расширить: `['weather','forecast','compare','accuracy','help']`,
  активна по умолчанию `weather` (и у кнопки, и у панели класс `active`).
- CSS: `#tab-weather.active{overflow:auto}` (как у остальных панелей).

### 3.2 Служебные словари (JS)

- **WMO → текст + эмодзи**: словарь в JS, как `VAR_NAMES`. Покрыть коды WMO из
  Open-Meteo (0,1,2,3,45,48,51,53,55,56,57,61,63,65,66,67,71,73,75,77,80,81,82,85,86,95,96,99)
  с русскими формулировками («Ясно», «Малооблачно», «Переменная облачность», «Пасмурно»,
  «Туман», «Небольшой дождь», «Дождь», «Ливень», «Снег» и т.п.) и эмодзи
  (☀️ 🌤️ ⛅ ☁️ 🌫️ 🌦️ 🌧️ ⛈️ 🌨️ и т.п.). Неизвестный код → «—» без эмодзи.
- **Направление ветра**: 8 румбов (С, СВ, В, ЮВ, Ю, ЮЗ, З, СЗ) из `wind_direction_10m`
  (градусы, шаг 45°, смещение 22.5°).

### 3.3 Блок 1 — Текущие условия (как Яндекс)

- Крупная температура `D.weighted.temperature_2m[curIdx]` (с «+»/«−»).
- Строка «Ощущается как N°» (`apparent_temperature`).
- Текст и эмодзи погоды — по `weather_code` в `curIdx`.
- Строка деталей (иконка + подпись, как в `buildConditions`):
  ветер «X м/с, СВ», давление «X мм рт. ст.» (`pressure_msl`, уже в мм рт. ст.),
  влажность «X%», «Восход / закат: HH:MM / HH:MM», «Долгота дня: X ч Y мин»,
  «Обновлено в HH:MM» (`generated_at`).

Восход/закат — из `D.daily.sunrise/sunset[0]` (сегодня). Долгота дня = разница.

### 3.4 Блок 2 — Прогноз по часам (как Яндекс)

- Горизонтальная прокручиваемая полоса: `overflow-x:auto`, ячейка фиксированной ширины.
- 48 часов от `curIdx` до `curIdx+48` (обрезать по длине массива).
- Ячейка: час «12:00» (из `D.time`), эмодзи (`weather_code`), температура «+23°»,
  вероятность осадков «20%» (`precipitation_probability`, если > 0 — показать).

### 3.5 Блок 3 — Прогноз на 10 дней (как Яндекс)

- Вертикальный список из `D.daily` и `D.daily_time` (10 записей).
- Строка: «Пн, 3 авг» (день недели + дата), эмодзи + текст погоды (по `weather_code`
  взвешенного консенсуса в 15:00 этого дня), вероятность осадков (%), справа
  «ночью +15° / днём +23°» (`temperature_2m_min` / `temperature_2m_max`).

### 3.6 Блок 4 — Подробный прогноз на 10 дней (как 76.ру)

- На каждый день из `D.daily_time`:
  - заголовок «Понедельник, 3 августа» (полное название дня недели + число + месяц);
  - 4 колонки **ночь / утро / день / вечер** — значения взвешенного консенсуса в часы
    **03 / 09 / 15 / 21** этого дня из `D.weighted`:
    - температура;
    - ветер «3 м/с, западный» (скорость + румб);
    - давление «755 мм»;
    - влажность «72%».
  - нижняя строка: «Восход / Закат / Долгота дня».
- День для каждого часа: `D.time[i].slice(0,10)` == `D.daily_time[d]`.
- Если части суток не хватает данных (конец массива) — ячейка с «—».

### 3.7 Справка
