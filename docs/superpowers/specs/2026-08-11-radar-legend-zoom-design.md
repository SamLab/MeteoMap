# Дизайн: легенда радара как у rainradar.ru + фикс зума

Дата: 2026-08-11

## Проблема

Пользователь просит:

1. **Легенда радара** — сделать как у оригинала rainradar.ru: четыре подписи
   `Облачность / Осадки / Гроза / Град` над оригинальным 12-цветным градиентом
   (сейчас в radar.html подписи `слабо / сильно` и другой градиент из 8 стопов).
2. **На зуме по умолчанию нет осадков** — карта открывается, но радар
   отрисовывается только после нажатия кнопки `+`/`−`.
3. **При смене зума не прорисовываются некоторые кадры** — во время
   зум-перестроения часть кадров таймлайна остаётся пустой.

## Диагностика

### Легенда оригинала (rainradar.ru)

Разметка оригинала — 4 непереключаемых `span` поверх градиента:

```html
<div class="legend">
  <span>Облачность</span><span>Осадки</span><span>Гроза</span><span>Град</span>
</div>
```

CSS оригинала:

```css
.legend{position:absolute;z-index:99999;bottom:10px;left:50%;width:240px;height:17px;
  margin-left:-120px;background-color:#42434bb8;padding:0 14px;display:flex;
  border-radius:20px;
  background:linear-gradient(to right,#8889bd,#595a95,#454696,#36b343,#81c81e,#c2d11e,
    #ffd000,#f29b17,#e1782e,#d23a4b,#b3107c,#b80db2);
  justify-content:space-between;align-items:center;box-shadow:0 0 2px #000}
.legend span{font-size:11px;color:#fff;text-shadow:0 0 4px #000;font-weight:600}
```

Это декоративная подпись диапазонов палитры (подтверждено пользователем: подписи,
не переключатели). Подписи распределены `justify-content:space-between` поверх
градиента; градиент — фон всего блока легенды.

### Баг «нет осадков на зуме по умолчанию» — первопричина

`template.html` вызывает `updateRadarFrame()` внутри `renderAll()` (строка 713),
то есть **сразу при инициализации страницы**, пока панель `#tab-radar` скрыта
(`.panel{display:none}`, `.panel.active{display:flex}`).

Воспроизведено headless-probe:

- `hidden-panel`: `mapsz=0x0`, тайлы не создаются (`canv=1`, `hits=525`);
- после активации вкладки: `mapsz=1200x717`, но Leaflet не знает о resize —
  canvas'ы по-прежнему не созданы;
- только клик по `+`/`−` заставляет Leaflet пересоздать тайлы — осадки
  «появляются».

Дополнительно: если карта инициализируется при 0×0, Leaflet может остаться в
некорректном состоянии, из-за чего при зум-перестроении часть кадров
таймлайна не отрисовывается (жалоба №3).

### Проверено, что НЕ является причиной

- Headless-прогоны `radar.html` напрямую (видимая карта) рендерят осадки на
  всех zoom 5..10 и при переключении кадров во время зума (проbe_zmfr).
- Манифест, тайлы rainradar.ru, палитра, `renderTile` — работают.

## Решение

### 1. `template.html` — ленивая загрузка iframe радара

- `updateRadarFrame()` больше не ставит `src` сразу. Вместо этого она сохраняет
  целевой URL в `f.dataset.radarSrc` и вызывает загрузку только если вкладка
  radar активна (панель `#tab-radar` имеет класс `active`).
- Обработчик клика по вкладкам: при активации `radar` — если у iframe есть
  `data-radar-src`, а `src` ещё не установлен, задать `f.src = f.dataset.radarSrc`.
- При смене города: `updateRadarFrame()` обновляет сохранённый URL; если вкладка
  radar уже активна — сразу перезагружает iframe.

Это гарантирует, что Leaflet инициализируется только на видимой карте
(не 0×0), и устраняет обе жалобы про зум.

### 2. `radar_template.html` — легенда как у оригинала

Заменить разметку легенды:

```html
<div id="legend">
  <span>Облачность</span><span>Осадки</span><span>Гроза</span><span>Град</span>
</div>
```

CSS: перенести позиционирование `#legend` (bottom, centered, z-index) в новый
блок; применить оригинальный фон-градиент из 12 стопов, `padding:0 14px`,
`height:17px`, `border-radius:20px`, `font-size:11px`, `text-shadow:0 0 4px #000`,
`justify-content:space-between`. Удалить внутренний `div.g` и старые подписи.

### 3. `radar_template.html` — самовосстановление размера карты (страховка)

Если карта всё же инициализируется при 0×0 (например, пользователь открыл вкладку
радара до полной разметки), добавить страховку: `map.invalidateSize()` через
`setTimeout(...,0)` после инициализации. Leaflet уже слушает `window.resize`,
поэтому lazy-load в `template.html` достаточно для обычного сценария.
Дополнительно используем один инстанс `RadarLayer`, созданный один раз после
загрузки кадров, и переключаем кадры через `overlay.redraw()` вместо
`removeLayer`+`addTo`, чтобы избежать гонок при зум-анимации: `redraw()` заставит
Leaflet пересоздать тайлы для текущего `cur.time`.

### 4. Тесты

- Обновить/добавить тесты в `tests/test_radar.py`:
  - легенда содержит `Облачность`, `Осадки`, `Гроза`, `Град`;
  - `template.html` больше не грузит iframe сразу (assert: src не ставится в
    `renderAll`, а загружается по активации вкладки);
  - сохранить существующие проверки (`data-tab="radar"`, `radar.html?lat=`,
    палитра, rainradar overlay).

## Критерии приёмки

- `python -m pytest -q` — новые/затронутые тесты проходят.
- Headless-probe index.html: после активации вкладки radar без зума `canv>=8`,
  `hits>0`.
- Легенда визуально совпадает с rainradar.ru (4 подписи, 12-цветный градиент).

## Объём изменений

- `template.html` — lazy-load iframe.
- `radar_template.html` — легенда, самовосстановление размера, один слой + redraw.
- `radar.html` — пересобрать (`tools/build_radar.py`).
- `tests/test_radar.py` — обновить/добавить проверки.
