# Дизайн: диапазон «мин-макс» числа моделей на строках дождя

## Проблема

Строки дождя показывают только **минимальное** число моделей с дождём за интервал
(`rainMinModels` / `mCnt` / `peakModels`): «до 23ч на 5.1мм с 79% · по 2 моделям».
При ~15 моделях одна цифра «по 2 моделям» выглядит неубедительно даже на консенсус-строке.

Хочется показывать диапазон `по 2-13 моделям`: первое число — минимум по часам
(как сейчас), второе — максимум по часам (час с наибольшим числом моделей за час).

## Решение

Число моделей на всех строках дождя становится диапазоном «мин-макс» по часам интервала.

### Формат

- Полные строки (wr1, wr2, заголовок «По часам»): `· по 2-13 моделям`.
- Коллапс при равенстве: если мин == макс → `· по 2 моделям` (как сейчас), без `2-2`.
- Единственное значение `1` (wr1 / «Вероятны Осадки», порог `>=1`): сохраняется форма
  `по 1 модели` (не диапазон).
- Виджеты (метео/метеоw компактный формат): `2-13м`, при равенстве `2м`, для 1 — `1м`.
- Пороги показа не меняются: консенсус-строки (wr2, consensus-ветка заголовка,
  `conCnt`) — только при `>=2`; model-based (wr1, fromModels «Вероятны Осадки»,
  `cntStr`) — при `>=1`.

### Триггеры

Определение интервалов, hasRainAt, conAt, findSrc/findCon, пороги — без изменений.
Меняется только вычисление и форматирование счётчика моделей.

## Механика

### template.html

1. Новая функция `rainModelRange(a,b)` — один проход по часам, возвращает
   `{mn,mx}` (мин и макс числа моделей с дождём по часам). Заменяет
   `rainMinModels` (текущие вызовы: wr1, строка 902 и wr2, строка 917).
2. Строка wr2 (917): `const R=rainModelRange(c0,c1); ... (R.mn>=2?' · по '+rcLbl(R.mn,R.mx):'')`.
3. Строка wr1 (902): `const R=rainModelRange(s,sE); const sLabel=R.mn>=1?'по '+rcLbl(R.mn,R.mx):''`.
4. Заголовок «По часам» (499-511): в цикле по часам трекается и максимум
   (`if(n>mX)mX=n`), `mcLbl` формируется через `rcLbl(mCnt,mX)`.
5. Хелпер `rcLbl(mn,mx)` — русский падеж:
   - `mn===mx` → `mn===1 ? '1 модели' : mn+' моделям'`
   - `mn<mx` → `mn+'-'+mx+' моделям'`
   - `mn<1` → `''`

### meteo.html / meteow.html

- В цикле `peakModels` (мин, метео 231-236, метеоw 193-198) трекается и максимум
  `peakMax`. После цикла оба значения при `Infinity` → `0`.
- `cntStr` (fromModels, порог `>=1`) и `conCnt` (consensus, порог `>=2`) — через
  хелпер `rcCnt(mn,mx)`:
  - консенсус: `conCnt=peakModels>=2?(' '+rcCnt(peakModels,peakMax)):''`
  - model-based: `cntStr=peakModels>=1?(' '+rcCnt(peakModels,peakMax)):''`
  - `rcCnt`: `mn===mx ? mn+'м' : mn+'-'+mx+'м'`
- `meteow.html` — кириллица в `\u`-эскейпах; правка внутри чисто ASCII
  (`.slice`, `'м'` — латиница/ASCII? нет, `м` кириллическая). Аккуратно: строка
  `2-13м` содержит латинские цифры и ASCII-дефис, `м` — кириллица, в meteo.html —
  обычный текст, в meteow.html — `'\u043C'`.
