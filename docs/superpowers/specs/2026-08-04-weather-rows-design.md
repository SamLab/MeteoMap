# Спека: строки «На 10 дней» и «Подробно на 10 дней» — компактная температура, осадки в мм, иконка кондиции и стрелка ветра

## Контекст

Вкладка «Погода» (задеплоена, коммит `e06585f`) содержит карточки «Сейчас», «По часам», «На 10 дней» и «Подробно на 10 дней». Пользователь хочет три изменения:

2. В «Подробно на 10 дней» вместо буквенного названия направления ветра — стрелка (куда дует ветер), плюс иконка кондиции в каждой части суток.
3. Обновить справку.

## Изменение 1 — строки «На 10 дней»

Файл: `template.html`, функция `buildWeather10` (стр. 304–318), CSS `.d10row` (стр. 74).

**Текущая строка:**
```
Пн, 3 авг | [иконка] В основном ясно | 10% | ночью +13° / днём +23°
```

**Новая строка:**
```
Пн, 3 авг | [иконка] В основном ясно | +23°/+13° | 0 мм / 10%
```

Правила:
- Температуры: `temp(tmax)+'/'+temp(tmin)` → `+23°/+13°` (градус у обеих). Источники: `D.daily.temperature_2m_max[di]`, `D.daily.temperature_2m_min[di]`.
- Последняя ячейка (всегда две части, разделитель ` / `):
  - осадки в мм: `fmt(D.daily.precipitation_sum[di])+' мм'`; при `null`/`undefined` — `—` (без «мм»);
  - вероятность: `num(D.daily.precipitation_probability_max[di])+'%'` всегда, включая 0%.
- Порядок колонок: день | условие | температуры | осадки/вероятность. Температуры идут сразу после условия.
- Убирается столбец вероятности (теперь он в общей ячейке с осадками).

CSS:
- `.d10row`: `grid-template-columns:100px 1fr auto auto`.
- Удалить `.d10pp` (стиль голубой вероятности — переносится на вложенный спан) и `.d10n` (muted ночная температура — больше не нужна, обе температуры обычным цветом).
- Добавить `.d10t{white-space:nowrap}` (температуры) и `.d10mm{color:var(--muted)}` (осадки мм), если нужно визуальное разделение. Допускается всё в одной ячейке `d10t`.

## Изменение 2 — «Подробно на 10 дней»

Файл: `template.html`, функция `buildWeatherDetail` (стр. 324–351), CSS `.dpart`/`.pt`/`.pw` (стр. 79–83).

**Текущая часть суток:**
```
день
+21°
3 м/с, северо-западный
750 мм
60%
```

**Новая часть суток:**
```
☀️ день
+21°
3 м/с [стрелка]
750 мм
60%
```

Правила:
- Иконка кондиции: `wcode(partVal(day, час, 'weather_code'))` → `[wtext, we]`. Иконка `we` выводится в строке `.pt` перед названием части: `☀️ день`. Название части (`x[0]` из `PARTS`) остаётся.
- Ветер (`.pw`): скорость как сейчас (`num(ws)+' м/с'`), направление — стрелка вместо `rumbFull(wd)`:
  - стрелка «куда дует ветер»: поворот `(wd+180)%360` по часовой (↑ = север), глиф `↑`;
  - разметка: `<span class="pwarrow" title="'+rumbFull(wd)+'" style="transform:rotate('+((wd+180)%360)+'deg)">↑</span>`;
  - полное название направления остаётся в `title` (тултип);
  - при `wd==null` — без стрелки (только скорость, как сейчас с «—»).
- Иконка и стрелка не добавляют новых зависимостей/CDN; эмодзи и глиф `↑` из системного шрифта.

CSS:
- `.dpart .pt` — контейнер для иконки+названия (flex или inline-разметка, без нарушения текущего вида).
- Добавить `.pwarrow{display:inline-block;font-size:12px;transform-origin:center}` (вращение применяется инлайн-стилем).
