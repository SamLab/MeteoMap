# Дизайн: вкладка «Спутник» (наукастинг Гидрометцентра)

**Дата:** 2026-09-03
**Статус:** одобрен

## Цель

Добавить на сайт MeteoMap отдельную вкладку **«Спутник»**, показывающую
**радар-наукастинг осадков Гидрометцентра России (~2 часа, кадры каждые 10 минут)**
на отдельной HTML-странице, **не затрагивая существующий радар**.

Имя «Спутник» условное — это радарный наукастинг, а не спутниковые снимки
облачности. Спутниковые снимки в эту итерацию **не входят** (отложено).

## Ключевое требование: не ломать радар

Существующий радар — единый механизм:
`radar_template.html` → `tools/build_radar.py` (инлайн Leaflet 1.6.0, CSS, палитры) → `radar.html`,
открывается во вкладке «Радар» через iframe `radar-frame`.

Чтобы гарантированно ничего не сломать:

- **НЕ изменяем:** `radar.html`, `radar_template.html`, `tools/build_radar.py`,
  JS-логику вкладки «Радар» (`radar-frame`, `updateRadarFrame`).
- **Новое (изолировано):**
  - `nowcast_template.html` — новый шаблон (эталон — текущий `radar_template.html`).
  - `nowcast.html` — собирается билдером из шаблона.
  - Библиотеки Leaflet/CSS/палитра переиспользуются из `tools/` (общие, не правятся).

## Изменения в site (template.html)

В шапку вкладок добавить вкладку **«Спутник»** (кнопка с `data-tab="satellite"`),
по образцу вкладки «Радар`, но с **отдельным iframe** `satellite-frame`:

1. **Кнопка** в `.tabs` (после «Радар»):
   `<button data-tab="satellite">Спутник</button>`
2. **Панель** (аналог `#tab-radar`):
   `<div id="tab-satellite" class="panel"><iframe id="satellite-frame" title="Спутник"></iframe></div>`
3. **JS переключения вкладок** (строка ~311): добавить `'satellite'` в список
   `['weather','forecast','radar','compare','accuracy','satellite','help']`.
4. **JS ленивой загрузки** (аналог блоков радиа, ~312-315): при активации
   `data-tab==='satellite'` установить `satellite-frame.src` из сохранённого URL.
5. **Функция установки URL** (аналог `updateRadarFrame`, ~982): при загрузке города
   задать `satellite-frame` URL `nowcast.html?lat=..&lon=..&zoom=8` (лениво, только
   при активной вкладке).

Вкладка **«Спутник»** независима от «Радар»: свой iframe, свой src. Переключение —
обычное переключение вкладок, обратной кнопки «← Радар» **нет** (по решению пользователя).

## Страница nowcast.html

Эталон структуры и кода — текущий `radar_template.html` (база, подписи городов,
молнии, таймлайн, палитра). Отличия — источник слоя наукастинга и его таймлайн.

### Содержимое
- **База-карта:** `https://rainradar.ru/tiles?z={z}&x={x}&y={y}` (копия из радара, `tms:true`).
- **Подписи городов:** `rainradar.ru/labels` (`LabelsLayer` — копия из радара).
- **Молнии:** Blitzortung + кнопка (копия из радара).
- **Слой наукастинга:** адаптированный `RadarLayer` — запрос тайла ГМЦ,
  чтение **R-канала** PNG → маппинг на палитру `PAL` (как в радаре).
- **Таймлайн:** из capabilities ГМЦ (10-мин кадры, ~2 часа) + кнопка play.
- **Легенда:** наша палитра (переиспользовать `#legend` из радара).
- **Строка статуса** (`#status`) и обработка ошибок — как в радаре.

## Источник ГМЦ (проверено вручную)

### Capabilities
```
GET https://meteoinfo.ru/hmc-output/nowcast3/nowcast.php
```
Ответ — XML WMS 1.1.1. В `<Extent name="time">` — список времён в UTC
(`2026-09-03T09:00:00.000Z,...`), шаг **10 минут**, горизонт **~2 часа** (≈13 кадров).
`<Name>` слоя = `1`.

### Тайлы (PNG)
```
GET https://meteoinfo.ru/res/nowcast/{z}0{x}0{y}/ncgi.php?tnz={z}&tnx={x}&tny={y}&inidt={ISO-время}
```
- Стандартные слайп-координаты Web Mercator `z/x/y`.
- Возвращает PNG 256×256 (RGBA) — прозрачный там, где нет осадков;
  **R-канал** кодирует интенсивность (как ra инradar).
- `inidt` — ISO-время кадра из capabilities.
- Проверено: тайл `6/39/19` (зона Ярославля) отдаёт корректный PNG 256×256.

### Покрытие
Маска слоя: ~42-68°N, 18-63°E (покрывает Ярославль и Цеденево).

### Зум/масштаб
Макс. нативный зум тайла ~8 (по маске `maxNativeZoom:8`). При зумах карты до 10
применять масштабирование как в текущем `RadarLayer` (`getDataZoom`/`getScale`).

## Поведение

- **Автообновление кадров:** перезапрос capabilities раз в **5 минут**
  (аналог `load()` в радаре, но интервал 5 мин), чтобы подтягивать новые кадры
  и сдвигать горизонт.
- **Ошибки:** статус «Наукастинг недоступен: <причина>», повтор через 30-60 с.
- **Нет осадков сейчас:** тайлы прозрачные — это нормальное состояние (Ярославль
  сейчас в сухую погоду полностью прозрачен).

## Сборка

Обобщить `tools/build_radar.py`, чтобы собирать оба файла из шаблонов:
- `radar_template.html` → `radar.html` (без изменений в результате).
- `nowcast_template.html` → `nowcast.html`.

Обе сборки используют общие `tools/leaflet.js`, `tools/leaflet.css`, `tools/palette.js`.
Убедиться, что `radar.html` в CI собирается как раньше (без регрессий).
В `.github/workflows/deploy.yml` добавить копирование `nowcast.html` в `_site/`
(строка ~64: `cp radar.html _site/`).
