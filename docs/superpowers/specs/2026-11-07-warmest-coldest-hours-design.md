# Design: Экстремумы тепла вместо заморозок в «Предупреждениях»

Дата: 2026-11-07

## Проблема

Блок «На 16 дней» дублировал информацию об экстремумах: строка «Теплее: …»
(самый тёплый час) и «Холоднее: …» (самый холодный час). Дубликат был в двух
местах (заголовок блока и блок «Предупреждения»), а заморозки в предупреждениях
показывали только интервал консенсуса ≤ 0 °C и минимум — без самого тёплого часа.

## Решение

1. **Блок «На 16 дней»**: строки «Теплее: …» и «Холоднее: …» удалены вместе с
   вычислением суточных максимумов/минимумов (`D.daily.temperature_2m_max/min`,
   `peakH`/`lowH`). Заголовок теперь содержит только часть про осадки.

2. **Блок «Предупреждения»** (иконка 🥶 сохранена): заморозки заменены на две строки
   об экстремумах температуры ближайших часов:

   - первая строка — самое тёплое (`Макс. …`), вторая — самое холодное (`Мин. …`);
   - в каждой строке два значения, разделённых « / »: первое — ближайшее
     (самый тёплый/холодный час по одной из моделей), второе — консенсусное
     (самый тёплый/холодный час по консенсусу `D.weighted.temperature_2m`),
     выделенное жирным.

   Формат: `Макс. <день> в <ч> <т>° / <день> в <ч> <т>°` /
   `Мин. <день> в <ч> <т>° / <день> в <ч> <т>°`.

3. **Справка** (`template.html`): колонка «Предупреждения» теперь описана как
   «дождь, экстремумы температуры, порывы ветра»; добавлено описание двух строк
   экстремумов с консенсусом и ближайшей моделью.

## Удалено

- Строки «Теплее: …» / «Холоднее: …» в `buildWeather16Title`.
- Логика заморозок: `frostRun`, `frostEndLabel`, `frostLbl`, интервал ≤ 0 °C.
- Сообщение-пустое состояние для блока экстремумов (мин/макс всегда есть при
  наличии данных).

## Тесты

- `test_d10_title_line_over_days`: «Теплее: »/«Холоднее: » больше нет; суточные
  `D.daily.temperature_2m_max/min` не используются в заголовке.
- `test_warnings_frost_column_replaces_thunderstorm`: колонка с `🥶` собирает строки
  `Макс. … / …` и `Мин. …` из консенсуса и ближайшей модели.
- `test_warnings_empty_messages`: сообщение «Заморозков …» убрано.
- `test_help_text_up_to_date`: новая формулировка колонки предупреждений.
- `tests/test_generation.py`: ключевые блоки отрисовки на месте.
