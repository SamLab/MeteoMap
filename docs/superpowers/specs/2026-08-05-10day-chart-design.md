# Редизайн секции «На 10 дней» — единый график

Дата: 2026-08-05

## Цель

Превратить табличный блок «На 10 дней» в непрерывный горизонтальный график без рамок и ячеек, объединяющий температуру и осадки на общем полотне. Макет согласован с пользователем в браузерных макетах v8–v12.

## Текущее состояние

`buildWeather10` (template.html:336-344) выводит табличные строки `.d10row` с колонками: день, кондиции, температура, осадки, облачность, влажность. На мобильном (media query ~:93-99) используется двухстрочный макет. Влажность и облачность присутствуют.

## Новый макет

Каждый день — узкая колонка (~56px) в общем полотне `.d10strip` без рамок и gap, с горизонтальной прокруткой. Сверху вниз в колонке:

1. **Пробирка (`.d10tube`, высота ~135px)**:
   - **Голубая заливка осадков (`.d10prec`)** — фон по всей ширине колонки, высота пропорциональна количеству осадков (`precipitation_sum`), сплошная через все дни. Если осадков нет — высота ~0.
   - **Полоска температуры (`.d10tbar`)** — узкая (8px) вертикальная полоска по центру, градиент красный→жёлтый→синий, от ночной температуры (низ) к дневной (верх).
   - **Дневная температура** — подпись по центру колонки, полностью НАД верхним краем полоски (красная, `#c0392b`).
   - **Ночная температура** — подпись по центру колонки, ПОД нижним краем полоски (синяя, `#2c6f9b`).
2. **Осадки текстом (`.d10mm`)** — `2мм/60%`, обычный вес (не жирный), тон серый.
3. **Кондиции (`.d10cond`)** — иконка погоды + `обл.45` (только облачность, влажность УБРАНА из этой секции).
4. **Дата (`.d10day`)** — `Ср 6` (день недели + число).

### Общая шкала температур

Позиции дневной/ночной подписей и полоски вычисляются по ОБЩЕЙ шкале для всех 10 дней:
- `scaleMin = min(all temperature_2m_min)`, `scaleMax = max(all temperature_2m_max)`.
- Дневная подпись дня с более высокой температурой стоит выше (например, +27° выше, чем +19°).
- Подписи позиционируются по центру колонки (`left:50%; transform:translateX(-50%)`).

### Данные

Из `D.daily`: `temperature_2m_min`, `temperature_2m_max`, `precipitation_sum`, `precipitation_probability_max`, `cloud_cover_mean`, `weather_code` (через `D.weighted` на 15:00 как сейчас), `DOW_S[d.getDay()]` + `d.getDate()`.

## CSS

Новые классы: `.d10wrap`, `.d10strip`, `.d10col`, `.d10tube`, `.d10prec`, `.d10tbar`, `.d10tday`, `.d10tnight`, `.d10mm`, `.d10cond`, `.d10day`. Старые `.d10row/.d10t/.d10cl/.d10hu` и мобильные правила заменяются. Пробирка без рамок — заливки сплошные.

## Что убирается

- Влажность из «На 10 дней» (в других секциях остаётся).
- Колонка/строки облачности отдельной строкой — теперь только `обл.N%` рядом с иконкой.
- Старые CSS `.d10row` grid-правил и мобильный двухстрочный макет.
