# Rain Episode No Day-Boundary Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Rain episodes («Ближайший дождь» in the 16-day block, the «Сегодня» hourstitle summary, and both weather widgets) must extend across midnight instead of being cut off at the day boundary, using the consensus rain formula and a `relDay` end label when the episode crosses days — consistent everywhere.

**Architecture:** Three independent single-file edits (template.html twice, meteo.html/meteow.html once) driven by string-assertion tests in `tests/test_radar.py` (long-standing project convention). No spec doc for this feature — speстик `docs/superpowers/specs/2026-09-25-rain-episode-no-day-boundary-design.md` is authoritative.

**Tech Stack:** Vanilla JS in static HTML (`template.html` is the source; `index.html` is regenerated by the CI deploy workflow — never edit `index.html` by hand). Widgets: `meteo.html` (literal Cyrillic) and `meteow.html` (Cyrillic stored as `\uXXXX` escapes — preserve that convention). Tests: pytest, string-assertion based.

**Global Constraints:**
- Consensus rain formula (identical everywhere): `code ИЛИ (мм энд>=0.1) ИЛИ (mm==null||mm<0.1 И prob>20)`.
- The episode is counted from `curIdx` (template) / from `idx` (widgets) to the end of data — no day-boundary `break`.
- Episode end = first non-rain hour after the last rainy hour (exclusive end, `Math.min(k,len-1)` / `endIdx=Math.min(jLast+1,len-1)`).
- When end date ≠ episode start date, render `relDay(endTs)+' '+enTime` (same as `enLabel` at template.html:525): `(eTime==='00ч'&&eDay!==sDay)?'00ч':(eDay===sDay?eTime:relDay(eTs)+' '+eTime)`.
- Preserve existing thresholds (`hasRainAt(j)||modelRainCount(j)>=2` second-pass triggers), rain type code, WMO codes `[51,53,55,56,57,61,63,65,66,67,80,81,82]`, and all widget gates (`peakModels>=1`/`>=2`, `rcCnt`).
- Widgets `meteo.html` and `meteow.html` must stay functionally identical after `\uXXXX` unescape.
- `meteow.html` has `DOW` (line 116); `meteo.html` needs a new `DOW` array since it lacks one.
- Full suite (non-integration) must pass: `$env:PYTHONIOENCODING="utf-8"; .\.venv\Scripts\python.exe -m pytest tests/ -m "not integration" -q` (currently 233 passed, 2 deselected).
- Commit only explicit paths — never `git add -A` (local `index.html`, `bot.php`, backup dirs must not be committed).
- Windows PowerShell 5.1: no `&&`; use `;` or `if ($?) {}`; set `[Console]::OutputEncoding = [Text.Encoding]::UTF8` before `git diff`.
